# jameslatajan.github.io

My personal portfolio, hosted for free on GitHub Pages.

- **Live site:** https://jameslatajan.github.io/
- **Repo:** https://github.com/jameslatajan/jameslatajan.github.io

## Setup

- Static site: `index.html`, `css/`, `js/`, `assets/`.
- Code lives on the `main` branch.
- `.gitignore` excludes the `.playwright-mcp/` test files.
- GitHub Pages turned on automatically because the repo is named `<username>.github.io`. It publishes from `main`.

## Updating the site

Run these in the project folder:

```
git add .
git commit -m "update"
git push
```

The site updates within about a minute of each push.
